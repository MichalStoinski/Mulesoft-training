# Mulesoft Training — American Flights API

## Purpose

This workspace supports a structured MuleSoft training programme centred on building and testing the **American Flights API**. It provides a hands-on environment for learners to design, develop, and validate RESTful API integrations using MuleSoft's Anypoint Platform, with Postman as the primary API client for testing and exploration.

## What's Inside

| Element | Description |
|---|---|
| **American Flights - module 1** | The first training module collection. Contains the HTTP requests used to interact with the American Flights API as exercises progress through the course. |

## Authentication

Requests in this workspace use a **Salesforce Consumer Key** stored securely in the team vault (`vault:salesforce_consumer_key_1a2g`). Never hard-code credentials directly into requests — always reference the vault variable.

## Getting Started

1. Ensure you have access to the team vault to resolve the `salesforce_consumer_key_1a2g` secret.
2. Open the **American Flights - module 1** collection and work through the requests in order.
3. Use the collection runner to execute all requests in sequence and validate responses.
